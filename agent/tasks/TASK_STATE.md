# Task State Board

## 1. 状态定义

- `todo`：已拆解，未开始
- `doing`：正在开发
- `review`：功能完成，等待复核或补验证
- `blocked`：存在阻塞
- `done`：已完成

## 3. 更新规则

- 开始任务前：将状态改为 `doing`
- 实现完成待核对：改为 `review`
- 确认完成：改为 `done`
- 出现外部阻塞：改为 `blocked` 并写清原因
